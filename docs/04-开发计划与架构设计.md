# 开发计划与架构设计

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        NDISender                            │
│  Qt UI → DXGI Capture → [HW Encoder] → NDI Send             │
│         → WASAPI Loopback ────────────→ NDI Audio            │
└─────────────────────────────────────────────────────────────┘
                              │ NDI (LAN)
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                       NDIReceiver                           │
│  Qt UI → NDI Recv → [Frame Sync] → DX11 Render              │
│                   → SDL2 Audio Playback                      │
└─────────────────────────────────────────────────────────────┘
```

## 3. 公共模块说明

| 模块 | 类 | 职责 |
|------|-----|------|
| ndi | `NdiContext` | `NDIlib_initialize` / `destroy` RAII |
| ndi | `NdiFinder` | 源发现与列表刷新 |
| ndi | `NdiSender` | 推流生命周期、音视频发送 |
| ndi | `NdiReceiver` | 拉流、Frame Sync、性能统计 |
| capture | `DxgiScreenCapture` | DXGI Desktop Duplication |
| encode | `MfH264Encoder` | Media Foundation H.264 低延时编码（HX） |
| render | `Dx11VideoRenderer` | UYVY/BGRA 纹理上传与绘制 |
| render | `VideoPreviewWidget` | Qt 窗口嵌入 DX11 |
| audio | `WasapiLoopbackCapture` | 系统音频环回采集 |
| audio | `SdlAudioPlayer` | 多声道 float 音频播放 |

## 4. NDISender 参数映射

| UI 参数 | NDI API |
|---------|---------|
| 源名称 | `NDIlib_send_create_t.p_ndi_name` |
| Groups | `NDIlib_send_create_t.p_groups` |
| clock_video / clock_audio | `NDIlib_send_create_t.clock_*` |
| 发送模式 High BW | BGRA + `NDIlib_send_send_video_v2_async` |
| 发送模式 HX | H.264 Annex-B + HX FourCC |
| 启用视频 | 控制是否调用 send_video |
| 启用音频 | 控制是否调用 send_audio_v3 |

## 5. NDIReceiver 参数映射

| UI 参数 | NDI API |
|---------|---------|
| 源选择 | `NDIlib_recv_connect` |
| color_format | `NDIlib_recv_create_v3_t.color_format` |
| bandwidth | `NDIlib_recv_create_v3_t.bandwidth` |
| allow_video_fields | `NDIlib_recv_create_v3_t.allow_video_fields` |
| Frame Sync | `NDIlib_framesync_create` |
| 硬件解码 | connection metadata XML |
| 启用视频/音频 | 接收线程内分支处理 |

## 6. 关键 API 参考

### Sender

```cpp
NDIlib_send_create_t send_create{};
send_create.p_ndi_name = "NDISender Demo";
send_create.p_groups = "Public";
send_create.clock_video = true;
send_create.clock_audio = false;
auto pSend = NDIlib_send_create(&send_create);

NDIlib_video_frame_v2_t frame{};
frame.xres = 1920;
frame.yres = 1080;
frame.FourCC = NDIlib_FourCC_type_BGRA;
frame.frame_rate_N = 60000;
frame.frame_rate_D = 1001;
frame.p_data = bgraBuffer;
frame.line_stride_in_bytes = width * 4;
NDIlib_send_send_video_v2_async(pSend, &frame);
```

### Receiver

```cpp
NDIlib_recv_create_v3_t recv_create{};
recv_create.color_format = NDIlib_recv_color_format_fastest;
recv_create.bandwidth = NDIlib_recv_bandwidth_highest;
recv_create.allow_video_fields = true;
auto pRecv = NDIlib_recv_create_v3(&recv_create);
NDIlib_recv_connect(pRecv, &source, nullptr, 0);

NDIlib_video_frame_v2_t video{};
switch (NDIlib_recv_capture_v3(pRecv, &video, &audio, nullptr, 1000)) {
case NDIlib_frame_type_video:
    // 处理并 NDIlib_recv_free_video_v2
    break;
}
```

### Frame Sync（平滑播放）

```cpp
auto pSync = NDIlib_framesync_create(pRecv);
NDIlib_framesync_capture_video(pSync, &video, NDIlib_frame_format_type_progressive);
// 渲染后 NDIlib_framesync_free_video
```

### 延时优化

1. 发送：`NDIlib_send_send_video_v2_async` + 编码器低延时（无 B 帧）
2. 接收：`NDIlib_recv_color_format_fastest`，禁用 Frame Sync
3. 实时处理队列，避免堆积

## 8. 风险与依赖

1. Advanced SDK Trial 未获批时可用免费 SDK 跑 High Bandwidth
2. HDR 发送需 Advanced 授权，首期 SDR 8-bit
3. 全屏独占游戏可能 DXGI 黑屏
4. FFmpeg 6.1 为可选 fallback，默认 NDI SDK 解码
