# 功能清单与变更记录

本文档记录 NDI-Study Demo 的**当前功能清单**，以及后续的 **BUG 修复**、**功能变更**、**功能新增**。架构细节见 [04-开发计划与架构设计](04-开发计划与架构设计.md)；联调步骤见 [05-联调验证指南](05-联调验证指南.md)。

## 一、当前软件功能

### 1. NDISender（推流 Demo）

| 功能 | 说明 |
|------|------|
| NDI 源发布 | 可配置源名称、Groups |
| 发送模式 | **High Bandwidth**（BGRA async）、**HX H.264**（Media Foundation 编码） |
| 视频源 | **DXGI 屏幕采集**（多显示器选择）；**Alpha 测试图**（1280×720 可配，无屏幕依赖） |
| 音频 | WASAPI 系统环回采集，可选启用 |
| 时钟 | 独立控制 `clock_video` / `clock_audio` |
| HX 码率 | 码率倍率 0.1–2.0 |
| Alpha 测试图 | 四边标识条、半透明/不透明图形、全透明背景；**测试图 Alpha** 水平滑动条（0–100%） |
| 发送 Alpha 反馈 | 推流时状态栏显示 **发送 Alpha: min~max**（实际推流 BGRA 采样） |
| 模式约束 | Alpha 测试图自动锁定 High Bandwidth，禁用音频 |

**无本地视频预览**；Alpha 效果需在 NDIReceiver 或 NDI Tools 中观察。

### 2. NDIReceiver（拉流 Demo）

| 功能 | 说明 |
|------|------|
| 源发现 | 刷新 NDI 源列表，选择并连接 |
| 色彩格式 | Fastest / Best / UYVY_BGRA / BGRX_BGRA 等 |
| 带宽 / 场 | Highest 带宽、允许 interlaced fields |
| Frame Sync | 可选，平滑播放（延时略增） |
| 硬件解码 | 连接 metadata 控制，Alpha 测试建议关闭 |
| 视频预览 | DX11 渲染 UYVY / BGRA；嵌入 Qt 窗口 |
| 音频播放 | SDL2 多声道 float 播放 |
| 性能统计 | 视频/音频帧计数、SDK 丢帧、**FourCC**、**Alpha: min~max** |
| Alpha 测试预设 | 一键：Fastest + 关硬件解码 + 棋盘格背景 |
| 透明检测背景 | 棋盘格底图，便于观察 Alpha |
| 预览 Alpha 倍增 | 水平滑动条（0–100%），**仅影响预览混合**，不改变 NDI 原始帧 |
| 保存 PNG | 导出当前 BGRA 显示帧（需正在接收且格式为 BGRA） |

### 3. 公共模块（common）

| 模块 | 主要能力 |
|------|----------|
| `ndi` | Context、Finder、Sender（BGRA/HX）、Receiver（Frame Sync、UYVA→BGRA） |
| `capture` | DXGI 桌面复制、`AlphaTestPattern` |
| `encode` | MF H.264 低延时编码 |
| `render` | DX11 渲染、棋盘格与 Alpha 混合、`VideoPreviewWidget` 线程安全预览 |
| `audio` | WASAPI 环回、SDL2 播放 |

新增条目请追加到 **§二** 顶部（最新在上），示例：


- **修复**：BUG、性能、崩溃、错误渲染等

## 四、已知限制与待办（非 BUG）

| 项 | 说明 |
|----|------|
| NDI Alpha 透传 | 部分 color_format / 硬件解码组合下 Receiver 统计可能为 `Alpha: 255~255`；需 Fastest + 关 HW 解码，或用预览 Alpha 倍增验证渲染 |
| HX 模式 | 不保证 Alpha；Alpha 测试请用 High Bandwidth |
| DXGI | 全屏独占应用可能黑屏 |
| HDR | 首期 SDR 8-bit，HDR 需 Advanced 授权 |
