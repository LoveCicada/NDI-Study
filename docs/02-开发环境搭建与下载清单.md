# 开发环境搭建与下载清单

## 系统要求

- **操作系统**：Windows 10/11 64-bit
- **处理器**：Intel/AMD，支持 SSE4.2 或更高
- **GPU**：NVIDIA / AMD / Intel（DX11、硬件编码可选）
- **内存**：8 GB 及以上（推荐 16 GB）
- **网络**：千兆局域网（NDI 推流测试）

## 必装组件

| 组件 | 版本 | 用途 | 下载链接 |
|------|------|------|---------|
| NDI Advanced SDK | 6.3.x | 核心库（HX 编解码、HDR 发送） | [申请 Trial](https://ndi.video/for-developers/ndi-advanced/software/) |
| NDI Tools | 6.3.x | 官方联调工具 | [https://ndi.video/tools/](https://ndi.video/tools/) |
| Qt | 5.15.2 | UI 框架（QWidget） | [Qt Archive](https://download.qt.io/archive/qt/5.15/5.15.2/) |
| CMake | 3.16+ | 构建系统 | [https://cmake.org/download/](https://cmake.org/download/) |
| Visual Studio | 2019/2022 | MSVC + Windows SDK | [VS 下载](https://visualstudio.microsoft.com/downloads/) |
| Windows SDK | 10/11 | DX11、DXGI、WASAPI | [Windows SDK](https://developer.microsoft.com/en-us/windows/downloads/windows-sdk/) |

### Visual Studio 工作负载

安装时勾选：

- **使用 C++ 的桌面开发**（Desktop development with C++）
- **Windows 10/11 SDK**
- **MSVC v142/v143 工具集**

### Qt 5.15.2 安装

1. 下载 [Qt 在线安装器](https://download.qt.io/archive/online_installers/) 或离线包
2. 选择 **MSVC 2019 64-bit** 组件
3. 记录安装路径，例如 `C:\Qt\5.15.2\msvc2019_64`

## SDK 部署

### NDI Advanced SDK

1. 访问 [NDI Advanced for Software](https://ndi.video/for-developers/ndi-advanced/software/) 提交 Trial
2. 获取 **License ID**（NDI 6 替代旧 Vendor ID）
3. 解压至项目目录：

```
third_party/NDI_Advanced_SDK/
├── Include/
├── Lib/x64/
└── Bin/x64/
    ├── Processing.NDI.Lib.x64.dll
    └── ...
```

> **注意**：NDI DLL 应与应用同目录部署，**不要**安装到系统 PATH，避免与其他 NDI 应用冲突。

### SDL2（可选预编译）

解压至 `third_party/SDL2/`，结构：

```
third_party/SDL2/
├── include/
├── lib/x64/
└── bin/x64/SDL2.dll
```

## 环境变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `NDI_SDK_DIR` | NDI SDK 根目录（CMake 查找） | `E:\SDK\NDI_Advanced_SDK` |
| `NDI_RUNTIME_DIR_V6` | NDI 运行时 DLL 目录 | `E:\SDK\NDI_Advanced_SDK\Bin\x64` |
| `CMAKE_PREFIX_PATH` | Qt 安装路径 | `C:\Qt\5.15.2\msvc2019_64` |
| `SDL2_DIR` | SDL2 根目录（可选） | `E:\code\private\NDI\NDI-Study\third_party\SDL2` |

也可在 CMake 配置时指定：

```powershell
cmake -B build -S . `
  -DNDI_SDK_DIR="E:/SDK/NDI_Advanced_SDK" `
  -DCMAKE_PREFIX_PATH="C:/Qt/5.15.2/msvc2019_64" `
  -DSDL2_DIR="E:/code/private/NDI/NDI-Study/third_party/SDL2"
```

## 构建步骤

```powershell
cd E:\code\private\NDI\NDI-Study
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

输出目录：`build/apps/NDISender/Release/` 与 `build/apps/NDIReceiver/Release/`

## 首次验证

1. 安装 **NDI Tools**，启动 **Screen Capture** 与 **Studio Monitor**，确认官方链路正常
2. 将 NDI SDK 的 `Processing.NDI.Lib.x64.dll` 复制到 Demo 输出目录（若 CMake 未自动复制）
3. 运行 `NDIReceiver.exe`，在源列表中选择 Screen Capture 输出
4. 运行 `NDISender.exe`，在 Studio Monitor 中查看推流

## 免费 SDK 降级方案

若 Advanced SDK Trial 尚未获批，可将 `NDI_SDK_DIR` 指向 [免费 NDI SDK](https://ndi.video/for-developers/ndi-sdk/)：

- Receiver 与 High Bandwidth Sender 可正常工作
- HX 硬件编码发送、HDR 发送需 Advanced SDK
